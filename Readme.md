# ParteAdmin

Pequeña aplicación frontend del proyecto Parcial (Admin).

Rápido inicio:

1. Instalar dependencias (desde `ParteAdmin/Frontend`):

```powershell
cd ParteAdmin/Frontend
pnpm install
pnpm run dev
```

2. Abrir en: http://localhost:5173/

Notas:
- Se agregó un archivo `.gitattributes` para normalizar finales de línea localmente, pero quedó desindexado a pedido (no está rastreado en el repositorio).
- Si querés que la normalización sea aplicada por el repo para todos los colaboradores, avisame y lo vuelvo a agregar al índice.
